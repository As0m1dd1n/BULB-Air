# BULB-Air — как мы работаем (читать первым)

## Проект в 5 строк
- NASA Space Apps 2026, задание *Be An Earth System Trend Detective!*
- Вопрос: становится ли воздух над городами Узбекистана грязнее (газ NO₂, спутник NASA OMI, 2004–2026)?
- Для каждого сезона даём честный вердикт: RISING / FALLING / SOURCES DISAGREE / NOT PROVEN YET.
- Главная фишка: показываем, сколько дней спутник реально видел город и какой тренд вообще можно было заметить.
- Сдаём: сайт (GitHub Pages), репо, 7 слайдов, страница проекта на сайте Space Apps.

Подробно: `README.md`. Правила для Claude Code: `CLAUDE.md`. Список работ: `TODO.md`.

## Уже решено (не переобсуждаем)
1. Только Узбекистан. Ташкент в центре, другие узбекские города рядом. Алматы и Бишкек убираем.
2. Одна переменная: NO₂ (не PM2.5, это прямо пишем).
3. Сезонные вердикты и NOT PROVEN YET не трогаем: жюри их хвалило.
4. Все числа только из `data/derived/results.json`. Никаких цифр «из головы».
5. Сайт, слайды и страница проекта на английском.
6. Сначала публичные ссылки и честные формулировки (TODO пп. 1–8), потом новые города (п. 16).

## Git
- Маленькие коммиты: `feat:`, `fix:`, `docs:`, `data:`.
- `git push origin <роль>`, потом Pull Request в `main`. Сливает только интегратор.
- Порядок слияния: сначала Наука, затем Сайт и Питч берут новые числа.
- Перед PR от Науки: `python scripts/analyze.py && python scripts/verify.py` должны пройти.

## Идеи
Идея пишется **GitHub Issue** с меткой `idea`, а не в чат: одна строка «что» и одна «зачем». Интегратор раз в сверку решает: делаем сейчас / после сабмита / нет. В чате идеи теряются.

## Ритм
- Сверка каждые 2 часа, 10 минут: готово / делаю / мешает.
- Заморозка кода: __:__ (за 3 часа до дедлайна). После неё только правка текста и ссылок.
- Сабмит: __:__.
