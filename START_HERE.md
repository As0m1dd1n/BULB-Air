# BULB-Air: how to open

1. Unzip the whole folder (do not open files from inside the zip).
2. **3D map**: open `map/index.html` in Chrome or Edge. Keep `data.js`, `borders.js`, `mosaic.js` and the `detail/` folder next to it.
3. **Trend website** (verdicts, slider, upload your own Giovanni CSV): open `docs/index.html`.
4. **Pitch deck**: `pitch/`.
5. **Data packs**: `extras/BULB-Air-data-2004-2021.zip` and `extras/BULB-Air-data-2022.zip` (CSV files with a README each).
6. **Method and sources**: `METHOD.md`, `REFERENCES.md`. Re-run the analysis: `pip install -r requirements.txt`, then `python scripts/analyze.py`.

Online copy of the 3D map: https://claude.ai/artifact/C927ZJ1GsuyqNRvf7D26Nz
